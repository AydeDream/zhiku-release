# 智库 Zhiku for Obsidian

**让知识服务于思考，让思考走向实践。**

智库是一款基于 Obsidian 的 AI 辅助阅读、知识管理与思考工具。

它不仅帮助用户阅读和理解书籍，还希望通过知识学习、方法实践和多视角思考，帮助用户理解问题、分析问题，并形成自己的判断。

## 核心功能

- **书架与原著阅读**：导入电子书，阅读原著，探索书籍内容。
- **AI 智能拆书**：提炼核心知识、思想观点及实用方法。
- **知识学习**：按章节理解书中的重要概念与知识。
- **复习巩固**：回顾与巩固已学习的知识。
- **实践应用**：将书中的方法应用到具体情境中。
- **知识图谱**：以可视化方式探索书籍的知识结构。
- **技能库**：整理并探索书籍中的实用方法与技能。
- **智囊团**：借助不同思想家的观点，从多个角度分析问题。
